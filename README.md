# Saurabh Kale — Marketing Portfolio

A responsive, hybrid professional/creative digital marketing portfolio, built with HTML, CSS and JavaScript. No build step, frameworks or hosting fees required.

## Preview locally

Open `index.html` in any browser. The site works without a local web server (Google Fonts require an internet connection).

## Customize before publishing

1. Open `index.html` and replace `YOUR_EMAIL@example.com` with your public professional email address.
2. Replace `https://www.linkedin.com/` with your exact profile link and `https://github.com/` with your profile link.
3. Put a shareable resume PDF in `assets/resume.pdf` (consider removing your home address and personal phone number). Replace the `resume-link` anchor's `href="#contact"` with `href="assets/resume.pdf"` and optionally add `download`.
4. Review the About text, employment details, location and every case-study claim. Only include metrics and client/company materials cleared for public sharing.
5. Optional: add screenshots, legitimate evidence, accessible project links and a custom domain.

## Publish on GitHub Pages

1. Sign in to GitHub and create a **public** repository named `YOUR_GITHUB_USERNAME.github.io` (replace with your exact username).
2. Upload the contents of this folder to the repository **root**. `index.html` must be visible at the top level next to `styles.css` and `script.js` (not buried in an extra folder).
3. Go to **Settings → Pages → Build and deployment → Source: Deploy from a branch**.
4. Choose branch `main` and folder `/(root)`, then save.
5. Visit `https://YOUR_GITHUB_USERNAME.github.io/` after publishing finishes. GitHub says changes can take up to 10 minutes.

GitHub docs: https://docs.github.com/en/pages/quickstart

## Files

- `index.html` — page content and structure
- `styles.css` — styling and responsive layout
- `script.js` — navigation, case study dialogs and current year
- `assets/favicon.svg` — website icon

## Notes

This starter intentionally uses abstract illustrations rather than unauthorised company graphics. Case study outcome copy is deliberately non-quantified until verified. The portfolio currently uses a placeholder email and default social links; personalize these before sharing with recruiters.
